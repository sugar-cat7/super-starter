# Desktop note count

The existing command manifest and local capability explicitly allow only `count_notes` alongside the original note commands. The Desktop count indicator calls `count_notes` in Rust and announces the result through a polite, atomic status region. Successful add/delete operations refresh it. Success payloads pass through the shared integer count schema. Invalid success payloads or native state/transport failures show an unavailable count and a keyboard-accessible retry; failures never display a fabricated zero or clear saved notes. There is no automatic retry.

# Desktop note count

The Desktop count indicator calls `count_notes` in Rust and announces the result through a polite, atomic status region. Successful add/delete operations refresh it. Invalid success payloads or native state/transport failures show an unavailable count and a keyboard-accessible retry; failures never display a fabricated zero or clear saved notes. There is no automatic retry.

The implementation follows the existing pinned Tauri API 2.12.2/native Tauri 2.12.2 and React 19.3.0 contracts.

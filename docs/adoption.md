pnpm's 24-hour release-age policy remains strict. esbuild/workerd build scripts are needed for their runtimes. External Edge/Gecko driver download scripts are explicitly denied because embedded native testing does not use them. Third-party dependency licenses remain with their packages; SDK-generated type headers are preserved. The original repository Apache-2.0 LICENSE is retained.

Local D1 migrations use Wrangler 4.148.0's stable local command. In the compatibility spike, `cf d1 migrations apply` applied the SQL but did not terminate, so it did not pass the CLI contract. The helper derives a disposable Wrangler migration config from the SDK's built Worker config; `cloudflare.config.ts` remains the only authored source. Migration and Vite/workerd share the same v3 state directory. Reapplication and seed both returned zero with Wrangler.

Unused dependencies are checked with Knip 6.40.0 ([configuration](https://knip.dev/reference/configuration), [CLI](https://knip.dev/reference/cli), [release](https://github.com/webpro/knip/releases/tag/knip%406.40.0)). Its Oxc-based analysis is compatible with native TypeScript 7 and discovers CSS imports and framework configuration. The newly released 6.41.0 is inside the release-age window and is not adopted. Service dependencies express process order; the native helper's WDIO CLI and WDIO's implicit local runner have narrow, documented configuration allowances.

Windows process cleanup uses the OS Job Object API, not PID ancestry snapshots. [Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects) and [CreateProcessW](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createprocessw) were read on 2026-10-09. A child is created suspended with atomic Job membership using the documented [PROC_THREAD_ATTRIBUTE_JOB_LIST](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-updateprocthreadattribute), then resumed; nested descendants retain ownership when intermediate parents exit. A thin PowerShell/C# adapter uses standard kernel32 APIs without elevation or execution-policy changes. Its real orphan/sentinel regression runs through the ordinary tools test command on each OS. Linux passed; Windows adoption remains provisional until the required Windows job actually executes.

Focused tests are rejected by the installed runners: Vitest `--allowOnly=false`, Playwright `forbidOnly`, and Mocha `forbidOnly`. Current installed types were checked against [Playwright test configuration](https://playwright.dev/docs/api/class-testconfig#test-config-forbid-only) and [Mocha exclusive tests](https://mochajs.org/#exclusive-tests). Deliberate focused/zero/skipped cases are part of the isolated fault rehearsal.

HTTP probes and tests consume response bodies before completing, following [Undici's resource-lifetime guidance](https://github.com/nodejs/undici#garbage-collection). A readiness probe keeps its existing one-second deadline through body completion; an actual HTTP fixture verifies that headers followed by a stalled body cannot mark the application ready. An independent generated-project spike passed two server tests, 19 Worker cases and the full 13-check gate without diagnostic instrumentation. Earlier intermittent Miniflare transport errors remain recorded with their failed assertions; body consumption has not established their root cause. The installed Miniflare connection-reuse design is documented in [workers-sdk PR 15781](https://github.com/cloudflare/workers-sdk/pull/15781). No SDK patch, automatic replay, concurrency exception or release-age override was added.

The native timeout fault uses Mocha's documented [test-level timeout](https://mochajs.org/next/features/timeouts/) inside a traditional test function. Installed WDIO 9.32.0 captures its wrapper timeout before the body runs, so this produces the asserted 50ms Mocha failure without the wrapper's earlier 47ms timer. An independent installed-SDK probe reproduced both paths three times. Ordinary native tests retain their 30-second timeout.

# Quality and evidence

`tools/quality/definitions.ts` is the check-ID/requirement/command source. `pnpm check` runs project-local Vite+ formatting, lint and strict type checking once, plus runtime boundaries, dependencies and documentation. Root options are common; package Vite configs own runtime/test/build only. SDK runtime types and generated route trees are excluded from formatting/lint, not silently substituted for source checks.

`pnpm test` runs tooling and package unit/contract tests. `pnpm gate:pre-pr -- --base <sha>` selects changed packages and reverse dependencies using real manifests. Root tooling/config/lock changes and an unknown base select everything. `pnpm gate:full` runs selected configuration checks, builds, real Worker tests, browser/a11y/VRT and native tests. Static checking remains global because it is lightweight. Missing scripts, no tests, failures and timeout fail. A nonselected package is `not_required` with a graph reason; blocked checks never count as passed.

Checks run sequentially to bound native/runtime memory; Vitest limits workers, and Vite+/Cargo own their task/build caches. The gate does not reuse previous successful reports. pnpm/Rust dependency caches accelerate warm execution without approving a different input. Reports in `artifacts/gate-*.json` include Git SHA/base, source content ID, OS/Node, selection, commands, timings and results. The gate rejects unexpected source changes; perform typegen/codegen with setup first.

Git hook installation is repo-local and repeatable. Existing `core.hooksPath` or active user hooks cause an explicit conflict; migrate them intentionally. Pre-commit validates a temporary exact index tree, links dependencies without pointing workspace imports at unstaged source, and never formats/restages/stashes. Pre-push checks detached copies of the actual pushed commits against each ref's remote SHA; it runs static/unit checks. Heavy build/runtime/native verification runs in the PR and final gate. The tiny shell Git adapters are the only Git-required shell entry; their work is Node TypeScript. No Agent-specific hook is advertised.

`pnpm template:verify` exercises generated configurations and isolated fault/recovery tests. Each fault must fail for the expected reason and pass after repair. CI runs this independently even if hooks were not used. Visual baselines are reviewed screenshots of the new sample; do not update them solely to silence a failure. Native E2E uses actual app/Rust IPC on the target OS; renderer units have separate names.

Normal project checks use `pnpm exec vp`. The exact staged snapshot invokes that same installed local Vite+ CLI directly: pnpm 12 otherwise attempts dependency preparation in the copied tree. This narrow Git integration keeps index validation read-only and avoids a second install or changed dependency input.
